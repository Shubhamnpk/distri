# Drishti v1.0.0 — Public data for Nepal

Drishti brings Nepal’s public data into one open civic intelligence platform. This first release brings together national indicators, public enterprises, infrastructure, disaster information, and public spending in a single place.

## What’s included

- **Economy:** World Bank indicators, IMF outlook series, Nepal Rastra Bank foreign-exchange rates, and economic trend visualizations.
- **Public enterprises:** Profiles and financial information for government-involved companies, alongside NEPSE-listed market data where available.
- **Infrastructure:** National Pride Project progress, project locations, hydropower information, and World Bank project records.
- **National map:** Province, district, and municipality boundaries with project, hydrology, weather, seismic, disaster, road, and protected-area layers.
- **Procurement:** Public tender information presented with links to the underlying source records.
- **Environment and disasters:** Live and recent information from DHM, BIPAD, USGS, and Open-Meteo feeds.
- **Nepal calendar:** Bikram Sambat and Gregorian dates with public holidays and fiscal-period context.

## Data and limitations

Drishti uses public government, multilateral, and open-data sources. Feeds have different publication schedules and levels of detail; a missing or delayed source can leave some figures unavailable. Use the source links on each page to inspect the original records.

## What’s next

We’ll keep improving source coverage, financial history, geographic detail, and the clarity of how each figure was reported.
